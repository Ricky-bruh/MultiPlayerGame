# 🎮 Pokémon-Style Multiplayer Browser Game

## 🌟 Overview

Dive into a nostalgic multiplayer experience reminiscent of classic Pokémon games! This browser-based game offers real-time exploration, dynamic map generation, and exciting multiplayer interactions.

## ✨ Key Features

### 🗺️ Gameplay
- **Retro Top-Down Movement**: Classic Pokémon-style navigation
- **Dynamic Map Generation**: Unique landscapes with grass, paths, and obstacles
- **Real-Time Multiplayer**: Interact with players in real-time
- **Customizable Characters**: Choose your color and name

### 🔒 Technical Innovations
- **Secure Multiplayer**: Robust anti-cheat system [ WORK IN PROGRESS ]
- **Persistent Sessions**: Seamless reconnection
- **Responsive Design**: Works across different devices

## 🚀 Quick Start

### Prerequisites
- 📦 Node.js (v14+)
- 📦 npm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/pokemon-multiplayer-game.git

# Navigate to project directory
cd pokemon-multiplayer-game

# Install dependencies
npm install

# Start the server
npm start
```

🌐 Open `http://localhost:3000` in your browser!

## 🎮 How to Play

### Controls
- **Movement**: `W` `A` `S` `D` keys
- **Join Room**: Select color, enter name
- **Create/Join Rooms**: Use lobby interface

### Game Modes
- 🌐 **Public Rooms**: Open to all players
- 🔐 **Private Rooms**: Invite-only gameplay
